## Seen in production

- **Ramp**: [How Ramp built a full context background coding agent on Modal](https://modal.com/blog/how-ramp-built-a-full-context-background-coding-agent-on-modal) (vendor case study, 2026-02)
  - Components: [Modal Sandboxes](https://mrpeppersdev.github.io/agent-infrastructure-landscape/systems/modal-sandboxes--modal-com), [Opencode (SST)](https://mrpeppersdev.github.io/agent-infrastructure-landscape/systems/opencode-sst--opencode-ai), [Temporal](https://mrpeppersdev.github.io/agent-infrastructure-landscape/systems/temporal--temporal-io), Chromium / VNC stack, Sentry, Datadog
  - "Postgres, Redis, Temporal, RabbitMQ, and every service an engineer would have locally."
- **Replit**: [Replit Agent (LangChain Breakout Agents)](https://www.langchain.com/breakoutagents/replit) (vendor case study)
  - Components: [LangGraph (orchestration)](https://mrpeppersdev.github.io/agent-infrastructure-landscape/systems/langgraph-orchestration--langchain-com), [LangSmith](https://mrpeppersdev.github.io/agent-infrastructure-landscape/systems/langsmith--langchain-com), [Anthropic Claude (foundation models)](https://mrpeppersdev.github.io/agent-infrastructure-landscape/systems/anthropic-claude-foundation-models--anthropic-com)
  - "using both the agent framework (LangGraph) and observability tool (LangSmith) together"
- **Lovable**: [Powering AI app generation at scale (Lovable)](https://modal.com/blog/lovable-case-study) (vendor case study, 2025-07)
  - Components: [Modal Sandboxes](https://mrpeppersdev.github.io/agent-infrastructure-landscape/systems/modal-sandboxes--modal-com)
  - "Lovable uses Modal Sandboxes at massive scale to run LLM-generated code for thousands of apps in safe and isolated sandboxes."
- **Anything**: [Anything: a vibe-coding platform with more than one million users](https://e2b.dev/customers/anything.md) (vendor case study, 2026-07)
  - Components: [e2b](https://mrpeppersdev.github.io/agent-infrastructure-landscape/systems/e2b--e2b-dev) ✓
  - "Anything uses E2B Templates to give every new project a preconfigured starting environment."
