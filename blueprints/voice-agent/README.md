## Security (OWASP Top 10 for LLM applications)

7 of 10 risks have a component aimed at them ([OWASP list](https://genai.owasp.org/llm-top-10/)).
- **LLM03 Supply chain** (practice): Run the stack check (GitHub Action) on every PR so archived or acquired components are flagged.
- **LLM08 Vector and embedding weaknesses** (practice): Enforce per-tenant access control in the vector store and memory layer; never mix tenants in one index without filters.
- **LLM10 Unbounded consumption** (gap): Rate limits, budgets and timeouts on model calls. Add a layer for it: Model gateway.
