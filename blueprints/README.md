# Reference blueprints

One reference stack per product type, generated by the [stack composer](https://mrpeppersdev.github.io/agent-infrastructure-landscape/build) from the catalog and checked against public write-ups of production systems. Each folder has a README (picks, cited reasons, production evidence, risk, OWASP coverage, cost), a `stack.yml`, a self-hosted variant and a `docker-compose.yml` starter.

Regenerate with `make blueprints` after catalog changes. Evidence lives in `data/blueprints/evidence.json`, images in `data/blueprints/images.json`.
