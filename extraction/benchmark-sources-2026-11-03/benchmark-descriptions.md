## Notes on ambiguous items

- **Terminal-Bench version names.** tbench.ai never uses "1.0" as a release name; the first release (2025-05-19) is "Terminal-Bench-Core-v0" (80 tasks), and the 2.0 post refers back to "the 1.0 benchmark". 2.1 is a fix release of 2.0 (same 89 tasks, 28 revised); 4.0 (2026-08-28) removes 8 and fixes 19 tasks and introduces semantic versioning (no 2.1→3.1 step: "Why is this 4.0 instead of 3.1?"). Terminal-Bench is both a dataset (Harbor registry) and a harness ("Terminal-Bench runs in Harbor"); Harbor itself is the eval package introduced with 2.0. **"Terminal-Bench Hard"** is not a tbench.ai release: it is Artificial Analysis's "hard subset of Terminal-Bench" (version and task count not stated on the AA page), now listed under AA's Legacy Evaluations. Scores across 2.0/2.1/4.0/Hard are not comparable; a versioned slug (`terminal-bench` + version field) is recommended.
- **FrontierCode versions.** Cognition's own page names no version and describes 150 tasks with Diamond/Main/Extended splits. "FrontierCode 1.1" (100 tasks) and "FrontierCode 2.0" (132 tasks, private) are Artificial Analysis's implementations of Cognition's sets; AA's pages say both are "Cognition's". FrontierCode has two metrics (pass rate vs weighted rubric score); AA reports "Mean score over three attempts per task", i.e. the rubric score, not the pass rate.
- **FrontierSWE 2.** Official pages (frontierswe.com, GitHub, SCORING.md) do not name "v1"/"v2"; the live site shows 34 tasks, 5 trials, 20-hour budget, and a category-gated 0–1 reward averaged as mean@5. Not a percent-resolved metric.
- **OSWorld lineage.** OSWorld (2024, 369 tasks) → OSWorld-Verified (2025-07-28, same tasks with fixes/infra) are one benchmark; OSWorld 2.0 (2026-06-26, 108 tasks, binary completion at 500 steps + partial reward) is a new task set; "OSWorld 2.1" is the `osworld-v2.1` bug-fix code release of 2026-09-16 ("updated agents, evaluation workflows"), not a different benchmark. Vendor-printed "OSWorld 2.1" scores are therefore OSWorld 2.0 tasks run on the 2.1 release.
- **AutomationBench vs AutomationBench-AA.** Zapier's leaderboard metric is strict full-task pass rate on a private held-out set; AA's variant uses a different headline metric (share of objectives completed, guardrail violation → 0) on 657 private tasks. Scores are not interchangeable.
- **MRCR "v2" / "256K".** Neither the OpenAI dataset card nor the Michelangelo paper names a "v2"; the only revision on the card is the 2025-12-05 bugfix. The card's bins run 4,096 → 1,048,576 tokens with 100 samples per bin; a 256K figure was not explicitly quoted on the fetched pages. The score is a 0–1 string-similarity ratio (partial credit), not a pass rate.
- **GraphWalks** scores F1, not a pass rate. **GDPval** is a win / win-or-tie rate against human expert deliverables; **GDPval-AA** and **AA-Briefcase** are Elo ratings; **Codeforces rating** (unfetchable) is by name a rating, not a percentage. **Vals Index**, **AA Intelligence Index** and **AA Coding Agent Index** are composite indices over other benchmarks, several of which (Terminal-Bench 4.0, FrontierCode, SWE-Atlas-QnA, AutomationBench-AA, HLE-Diamond, GDPval-AA) appear in this table individually.
- **HLE-Diamond** (AA) is "a refined 1,000-question subset" of HLE that AA says is "not directly comparable" to HLE.
- **NL2Repo.** Vendors print "NL2Repo"; the official paper title is "NL2Repo-Bench". Its ~18.8k-token requirements document is an input-size fact, not a 100k+ context test. A search result also surfaced an unrelated 2024 use of the term "NL2Repo" in a different paper; that page was not fetched and is not recorded here.
- **SWE-Atlas-QnA** is one of three SWE Atlas sub-benchmarks (QnA 124, Test Writing 90, Refactoring 70); only QnA has a published leaderboard per the HF card. Its metric is an LLM-judged all-rubric-items resolve rate. A search snippet mentioned an AA evaluation named "SWE-Bench-Pro-Hard-AA"; no official page for it was fetched, so nothing is recorded.
- **EEBench** and **CursorBench** official pages do not state task counts or release dates (CursorBench's earliest dated version is 3.0 on 2026-03-11); CursorBench does not define its percentage score.
- **Codeforces rating:** official source not fetchable (Cloudflare challenge on codeforces.com); per the task rules nothing else is recorded.
